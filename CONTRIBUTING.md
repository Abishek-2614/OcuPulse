# Contributing

1. Open an issue describing the change and its motivation.
2. Make the smallest reproducible change possible.
3. Add or update tests for signal-processing changes.
4. Run python -m unittest discover -s tests -v and the sample-data CLI before opening a pull request.
5. Document hardware, board package, library versions and test conditions.
6. Do not include identifiable human data, credentials, Wi-Fi secrets, or unapproved clinical data.
7. Do not present exploratory output as an IOP diagnosis or claim clinical validity without appropriate evidence.

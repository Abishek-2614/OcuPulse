# Technical references

These links identify upstream library documentation used to design the acquisition sketch. Confirm the exact library version installed in the project and follow each dependency's license and instructions.

1. Pololu, VL53L1X Arduino library: https://github.com/pololu/vl53l1x-arduino
2. SparkFun, MAX3010x Sensor Library: https://github.com/sparkfun/SparkFun_MAX3010x_Sensor_Library
3. Adafruit, SSD1306 library: https://github.com/adafruit/Adafruit_SSD1306
4. Adafruit, GFX library: https://github.com/adafruit/Adafruit-GFX-Library

The synthetic example and exploratory feature code are not sourced from biomedical participant data. The listed dependencies are referenced but are not copied into this repository.
